# Импорт боевой Excel-базы

- Статус: актуально
- Обновлено: 2026-08-26

## Правило хранения

Боевые Excel-файлы, дампы и выгрузки не коммитятся, не включаются в Docker-образ
и не хранятся в проектной документации. Файл передаётся отдельно и удаляется из
временного защищённого каталога после подтверждения импорта.

## Рекомендуемый импорт

1. Войти в административную панель.
2. Создать или выбрать город.
3. Выбрать загрузку готовых поставщиков.
4. Загрузить `.xlsx` с колонками `Артикул`, `Название`, `Поставщик` и `Цена`.
5. Проверить количество поставщиков и позиций, затем выборочно открыть ценники.

Фишки `ВЕГАН` и `ХИТ` администратор проставляет после импорта вручную.

## CLI-импорт из доверенного окружения

При необходимости можно использовать скрипт, не копируя Excel в репозиторий:

```bash
BASE_URL=https://labels.example.com \
NUXT_ADMIN_LOGIN=admin \
SEED_CITY='Москва' \
SEED_FILE=/secure-import/labels.xlsx \
npm run seed:production
```

До запуска `NUXT_ADMIN_PASSWORD` должен быть передан процессу из защищённого
хранилища окружения. Значения пароля и реального пути не сохраняются в
`.env.example`, истории Git, документации или журналах CI. После импорта нужно
удалить временный файл и проверить позиции через административную панель.
