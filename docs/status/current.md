# Текущее состояние

- приложение перенесено на Nuxt 4, Vue и TypeScript;
- постоянные данные хранятся в PostgreSQL;
- сохранены партнёрская панель, административная панель, импорт Excel, будущие версии цен и PDF;
- добавлены healthcheck, Docker, Compose, Traefik, Gitea Actions и проверки качества;
- боевая Excel-база хранится в `data/production` и загружается командой `make seed`;
- учётные данные и строка подключения задаются только переменными окружения.

Перед вводом в эксплуатацию DevOps должен создать роль/базу PostgreSQL, внешние сети Docker, DNS и TLS-маршрут Traefik.
