# История изменений

## 2026-09-01 — граммы и миллилитры в ценниках

- Для позиции добавлена единица измерения `г` или `мл`; существующие записи
  безопасно переводятся на значение `г` миграцией `003_add_measure_unit.sql`.
- Администратор может выбрать единицу вручную или передать её через Excel.
- Импорт автоматически распознаёт обозначение миллилитров в количестве и
  названии позиции.
- Партнёрский каталог и PDF отображают единицу, сохранённую у позиции.

## 2026-08-30 — финальная локальная проверка каталога ценников

- Добавлен поиск города в партнёрской и административной панелях.
- Администратор может переименовать существующего поставщика; новое название
  применяется во всех связанных городах без потери позиций и версий цен.
- Переименование проверяет пустые и повторяющиеся названия.
- Финальная проверка: lint, typecheck, 15 тестов, покрытие выше 80% и Nuxt-сборка.

## 2026-08-28 — локальное обновление перед приёмкой

- В партнёрской панели добавлены поиск поставщика и пояснение выбора текущей или
  будущей даты цен.
- В административной панели добавлено удаление города вместе с поставщиками,
  которые не используются в других городах.
- Добавлены поле и фишка `НОВИНКА`; PDF размещает до трёх фишек без наложения на
  название.
- Администратор может искать поставщиков выбранного города и подключать к нему
  поставщика из общей базы; существующие версии цен и позиции переиспользуются.
- В локальную тестовую сборку встроена готовая food-only база из 4 443 позиций
  и 198 поставщиков; загрузка Excel перед проверкой не требуется.
- Поставщики распределены по 46 регионам на основании структуры папок
  `Ценники`; `Интегрита` оформлена отдельным городом и удалена из остальных
  городов. PDF не анализировались.
- Из названий ценников удаляются окончания вида `100Г_ИНТ` и `115Г_БЫК`, а
  извлечённая граммовка остаётся в отдельном поле.
- Варианты без буквенного обозначения граммов, например `55_ЛБН`, также
  очищаются; пустые города скрываются из партнёрского каталога.
- Добавлены миграция `002_add_new_badge.sql`, тест раскладки фишек и изолированный
  локальный деморежим.
- Обновление не опубликовано в Git и не развёрнуто: ожидается разрешение владельца.

## 2026-08-28 — первый production-релиз

- Production env сохранён в закрытом Git по явному решению владельца; домен
  установлен в `price.apps.onepricecoffee.com`, файл исключён из Docker context.
- Release `9c1a9f3` собран и запущен отдельным Compose-проектом за общим Traefik.
- Созданы отдельные PostgreSQL role/database `oneplus_price`, применена миграция
  `001_initial.sql`.
- Включён nightly backup с 14-дневной ротацией; populated dump успешно
  восстановлен во временную базу и сверен по количеству таблиц.
- Проверены HTTPS health, TLS, главная страница, входы администратора и партнёра,
  изоляция контейнера и отсутствие ошибок в логах.
- Production-изменения опубликованы в PR №1; штатный merge в `main` остаётся
  завершающим шагом Git-процесса.
- Сопутствующие эксплуатационные изменения опубликованы в infrastructure PR №1.
- Финальный аудит обнаружил ошибку PostgreSQL upsert при дубликатах артикула;
  добавлены дедупликация с правилом «последняя строка выигрывает» и regression-тест.
- Исправленный release `03bb374` прошёл 7 тестов, покрытие, Nuxt/Docker build и
  изолированный API regression на временной PostgreSQL, затем заменил production
  release. `9c1a9f3` сохранён для rollback.

- Приложение приведено к инфраструктурному контракту общего Traefik и PostgreSQL.
- Стандартизированы команды проверки, покрытия, сборки и Compose.
- Боевая Excel-выгрузка исключена из Git и Docker-образа.
- Добавлены инструкции безопасного импорта, публикации, развёртывания и отката.
- Проектная память приведена к структуре корпоративного шаблона.
- Чистая ветка `main` опубликована в корпоративном репозитории `ONEPRICES`.
