# ADR-0001: PostgreSQL для постоянных данных

- Статус: принято
- Дата: 2026-08-26

## Контекст

Исходная версия использовала Cloudflare D1. Среда OGC запускает приложение в Docker за общим Traefik и предоставляет общую PostgreSQL.

## Решение

Использовать отдельные роль и базу PostgreSQL, подключаемые через `NUXT_DATABASE_URL`. В качестве драйвера выбран `postgres`: он совместим с Nitro/Node, поддерживает транзакции и не требует отдельного ORM. Схема версионируется SQL-миграциями.

## Последствия

Приложение зависит от доступности PostgreSQL. Оно подключается к общей базе через
внешнюю сеть `postgres-internal`, но использует отдельные роль и базу. Резервное
копирование, ротация секрета и обновление сервера базы остаются ответственностью
общей инфраструктуры. Production-данные не хранятся в Git или Docker-образе.
