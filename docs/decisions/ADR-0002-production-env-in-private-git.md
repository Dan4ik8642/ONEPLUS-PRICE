# ADR-0002: Production env в закрытом Git

- Статус: принято
- Дата: 2026-08-28

## Контекст

Владелец проекта явно разрешил сохранить переданный production env в закрытом
внутреннем репозитории `ONEPRICES`. Это исключение из исходного правила хранения
секретов только на сервере.

## Решение

- Хранить переданный набор переменных в `.env.production`.
- Не дублировать значения файла в документации, CI-логах и пользовательском выводе.
- Исключить `.env.production` из Docker build context, несмотря на его наличие в Git.
- На сервере устанавливать копию файла с режимом `0600` и подставлять точный тег
  release image без изменения исходных секретных значений.

## Последствия

Компрометация Git-сервера или доступа к репозиторию раскрывает production
учётные данные. При изменении видимости репозитория, утрате доступа или отзыве
этого решения все сохранённые credentials нужно немедленно ротировать и удалить
из актуальной и исторической Git-версии отдельной согласованной процедурой.
