# План: первая публикация ONEPLUS-PRICE в OGC

- Статус: завершено
- Обновлено: 2026-08-28
- Связанное решение: [ADR-0001](../decisions/ADR-0001-postgresql.md)

## Цель

Подготовить воспроизводимую и проверенную сборку ONEPLUS-PRICE, совместимую с
общими Traefik и PostgreSQL, и впервые опубликовать её в корпоративном Gitea.

## Вне рамок

- Развёртывание на сервере без готового контура DevOps.
- Создание DNS, production-секретов, роли или базы PostgreSQL.
- Хранение боевой Excel-выгрузки в Git.

## Работа

- [x] Прочитать документацию OGC и проверить проект на соответствие.
- [x] Привести Compose и PostgreSQL-сеть к инфраструктурному контракту.
- [x] Исключить боевую выгрузку из Git и Docker-образа.
- [x] Обновить команды проверок и проектную память.
- [x] Выполнить lint, типы, тесты, покрытие и production Nuxt-сборку.
- [x] Создать чистую корпоративную историю с русским коммитом.
- [x] Опубликовать `main` и проверить upstream.
- [x] Подтвердить Compose и Docker-сборку в воспроизводимом окружении Node.js 24.

## Критерии готовности

- Проверки, покрытие, Nuxt-сборка и Docker-конфигурации проходят.
- На момент завершения публикации в Git отсутствовали `.env`, секреты, приватные
  ключи и production-данные. Последующее исключение для `.env.production`
  оформлено отдельным [ADR-0002](../decisions/ADR-0002-production-env-in-private-git.md).
- Ветка `main` опубликована без force-push и синхронизирована с Gitea.
- Инструкция DevOps содержит запуск, healthcheck, импорт и откат.
