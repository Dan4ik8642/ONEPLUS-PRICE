## Локальная проверка

Запуск выполняется с `NUXT_DEMO_MODE=true`. Демоданные хранятся только в памяти
процесса и восстанавливаются после перезапуска. Production URL, база данных и
репозиторий при локальной приёмке не изменяются.

Готовая база загружается из встроенного проверенного JSON, сформированного из
файла `Готовая база ценников — только готовая еда.xlsx`. Распределение по
городам сформировано только по именам папок и файлов каталога `Ценники`; PDF не
открывались. Поставщики базы без найденной региональной связи остаются в общей
базе администратора и могут быть добавлены в город вручную.
