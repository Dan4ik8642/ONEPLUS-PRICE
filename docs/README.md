# Проектная память

- `context/project.md` — назначение, роли и границы продукта.
- `status/current.md` — текущее состояние и известные ограничения.
- `plans/roadmap.md` — последующие этапы.
- `decisions/` — архитектурные решения.
- `operations/` — Git, эксплуатация и развёртывание.

Перед началом работы читать контекст и текущий статус. После изменения поведения обновлять статус, roadmap или ADR.
