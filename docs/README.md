# Проектная память

Эта папка — каноническая долговременная память ONEPLUS-PRICE. Она позволяет
восстановить состояние продукта и правила эксплуатации без чтения переписки.

| Раздел | Назначение |
| --- | --- |
| `context/` | Назначение, роли, границы и инварианты продукта |
| `status/` | Единственная актуальная сводка состояния |
| `plans/` | Roadmap и планы конкретных работ |
| `decisions/` | Неизменяемые архитектурные решения |
| `changes/` | Хронология завершённых изменений |
| `operations/` | Разработка, Git, импорт данных и развёртывание |

Перед задачей нужно прочитать `AGENTS.md`, текущий статус, roadmap, активный план
и только относящиеся к задаче решения и эксплуатационные инструкции. Перед
завершением обновляются статус, связанный план, changelog и затронутые инструкции.

Документация ведётся по-русски, даты записываются в формате `YYYY-MM-DD`.
Production-секреты, пароли и содержимое боевых выгрузок здесь не фиксируются.
По явному решению владельца готовый `.env.production` хранится только в закрытом
репозитории; его значения не переносятся в проектную память и журналы.
