# Развёртывание в Docker

## Требования

- Docker Engine 24+;
- Docker Compose v2;
- reverse proxy с HTTPS для боевого домена;
- минимум 1 ГБ RAM и 2 ГБ свободного диска.

## Первый запуск

1. Скопировать .env.example в .env.
2. Заменить оба пароля и SESSION_SECRET. Для секрета использовать случайную строку длиной не менее 32 символов.
3. Выполнить: docker compose up -d --build
4. Проверить: docker compose ps

Приложение слушает порт 3000. На reverse proxy направить домен на http://127.0.0.1:3000.

## Загрузка боевой базы

Есть два равнозначных способа:

1. В админке выбрать город и нажать «Выбрать общую базу».
2. Однократно выполнить автоматическую загрузку включённого файла:

   docker compose --profile seed run --rm seed

Повторный запуск безопасен: поставщики и позиции обновляются по имени поставщика и артикулу, а не дублируются.

## Хранение данных и резервные копии

Локальная SQLite/D1-база хранится в Docker volume one_price_data. Не удалять volume при обновлении контейнера.

Перед обновлением сделать резервную копию volume. Команда приведена ниже:

docker run --rm -v one-price-portal_one_price_data:/data -v ./backup:/backup alpine tar czf /backup/one-price-data-backup.tar.gz -C /data .

Восстановление выполнять только на остановленном приложении.

## Обновление

1. Сделать резервную копию volume.
2. Заменить исходники проекта.
3. Выполнить docker compose up -d --build.
4. Проверить docker compose logs --tail=100 app.

## Переменные окружения

- ADMIN_LOGIN, ADMIN_PASSWORD — доступ администратора;
- PARTNER_LOGIN, PARTNER_PASSWORD — общий доступ партнёров;
- SESSION_SECRET — подпись серверных сессий;
- PORT — внутренний HTTP-порт, по умолчанию 3000.

Файл .env нельзя коммитить или передавать вместе с архивом проекта.
