# One Price — портал ценников

Боевой проект для управления поставщиками, версиями цен и печатью ценников 60×40 мм.

## Что умеет система

- партнёр выбирает город, поставщика и текущую или будущую версию цен;
- формирует PDF A4 по 18 ценников на листе;
- администратор загружает готовую общую базу поставщиков в выбранный город;
- поставщики из Excel создаются автоматически и получают прайс-лист «Текущие цены»;
- сохраняется загрузка Excel в отдельную версию конкретного поставщика;
- позиции можно добавлять, редактировать, отключать и удалять вручную;
- можно заранее создать будущую версию цен с датой начала;
- поставщика можно связать с несколькими городами.

Технологии: TypeScript, React 19, Vinext/Vite, Cloudflare-compatible Worker, SQLite/D1, pdf-lib и SheetJS.

Основная боевая таблица находится в data/production/Готовая база с ценами.xlsx.

Подробный запуск описан в РАЗВЕРТЫВАНИЕ_DOCKER.md.
